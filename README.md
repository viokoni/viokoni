# vioKoni

Website, privacy policy and support for **vioKoni**, a media player for Apple TV.

- Website: https://viokoni.com
- Support: https://viokoni.com/support/
- Privacy policy: https://viokoni.com/privacy/

vioKoni provides no content. It plays sources you already have: an Xtream Codes
account or an M3U playlist from a provider you are legally entitled to use.

**Found a bug or have an idea?** [Open an issue](../../issues/new/choose).
Issues are public: never post passwords, server addresses, playlist links, API
keys, or names of providers or channels. For private questions write to
support@viokoni.com.

The app's source code is not in this repository.
